# Relógio Futurista

Este é um relógio futurista criado com HTML, CSS e Python (Flask). Ele exibe a hora atual com um visual moderno.

## Como rodar o projeto

1. Clone este repositório.
2. Instale as dependências com `pip install flask`.
3. Inicie o servidor: `python app.py`.
4. Acesse `http://127.0.0.1:5000` no navegador.

## Tecnologias usadas
- **Python** (Flask)
- **HTML**
- **CSS**
- **JavaScript**
